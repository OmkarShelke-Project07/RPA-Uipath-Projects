# UiPath Projects

This repo contains a few UiPath projects I've worked on. I'm adding them here to keep the workflows and examples in one place.

## Projects

### AI Interview Preparation Agent

The JD Analyze Agent.uis file is for an agent that takes a job description and helps prepare for an interview by analysing the role and suggesting relevant questions.

![AI Interview Preparation Agent](https://github.com/user-attachments/assets/5915073e-d20b-47fd-9edc-716e75f2c4ed)

### PDF Extraction

The PDF_Extraction folder contains a project for extracting information from PDF files.

### School Database Web Scraping

The SchoolDataBase_Web Scraping folder contains a web-scraping project related to school database information.

## Opening the projects

Clone or download this repo, then open the project files with the relevant UiPath tool. You may need to configure your own paths, inputs, or credentials before running a workflow.

These projects are examples of my automation work, so setup details can vary between folders. Check the files in each project before running it.
